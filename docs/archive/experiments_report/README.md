# ISDA 2026 experiments report

`main.pdf` — overview of all runs in `presentations/isda_new/experiments/{esmda,filtering,filter_smoothing}`.

- `sections/*.tex` — setup, ESMDA, filtering, filter smoothing, cross-method comparison.
- `sections/*_tables.tex` — auto-generated from `run_summary.yaml` by `scripts/extract_*.py` (`make tables`).
- `figures/` — cropped panels generated by `scripts/make_*/crop_*` (`make figures`).
- `make pdf` rebuilds with latexmk.
