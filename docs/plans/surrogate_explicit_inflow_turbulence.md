# Explicit inflow turbulence for the Tadpole surrogate

Working design note (2026-09-16). Findings verified against
`training_data/pyudales_idealized` and `model_weights/dft_s`; design not yet
implemented. Probe scripts live in `.temp/inflow_probe/` (scratch, not committed).

## 1. What the data actually contains

`training_data/pyudales_idealized` was generated by
`scripts/neural_surrogate/generate_random_geometries_training_data.py` as
sequential single-model uDALES runs with `inlet_turbulence.enabled: true`
(intensity 0.25, L = 12 m, dtdriver 0.5 s) and `seed: null`. `seed: null`
resolves to `derive_seed(experiment_name)` and the generator never overrides the
template `experiment_name: "999"` (`conf/model/pyudales.yaml`). Consequences:

| Fact | Evidence |
|---|---|
| Every one of the 260 samples (train, val, test) uses the same seed. | `state/*/sample_*.nc` `title` = `fielddump.000.000.999.nc` for all 260; generator passes no `experiment_name`/`seed` in `fm_overrides`. |
| 224 samples replay the *same record window* (records 0..2403); 36 repeated-geometry train samples get records 2400..4803 via the persisted turbulence clock. | `geometries.csv` grouping + `ForwardModel._elapsed_time`. |
| Same-grid samples share the noise bit-for-bit; only the AR(1) coefficient (mean speed) and the profile scaling differ. | Stored inlet-column u' (x = -30 m, time-mean removed) correlates 0.83-0.96 between train samples 0000/0003/0009/0011/0017/0018 (all ny = 48); 0.94 after high-pass. |
| The realization is exactly regenerable offline. | `build_driver_planes` with (jtot, ktot, ylen, zsize) from the state file, params from `sampled_params.nc`, `power_law` alpha 0.25, `derive_seed("999")` reproduces the stored first-column u' at r = 0.96-0.97 (samples 0000, 0001, 0003) when the record index is `round((t_label + 205) / 0.5)`. |
| Saved frame label t sits at physical time t + 205 s. | The +10-record shift above is sharp (r drops to 0.6-0.8 one record either side). Spinup trim drops 40 frames; the fielddump's first frame is one interval after t = 0. |
| The inlet forcing is unpredictable from the state at the 5 s cadence. | AR(1) e-folding 0.8-1.5 s (a = 0.52-0.72 at dt 0.5). Lag-1 autocorrelation of stored u' at 5 s: 0.12 at the inlet, 0.29 at x = -14, 0.39 at x = +2, 0.55 at x = 98. |
| Nothing about the realization is stored with the data. | attrs carry only geometry_stl/source/resolution; params carry inflow_angle, velocity_magnitude, pressure_gradient_magnitude. |

## 2. What the surrogate sees and what it learned

`model_weights/dft_s` (TadpoleTimeStepper S, frozen `tadpole_ae_s_new`): input =
one frame of (u, v, w), three scalars through a global FiLM, static geometry
branch; deterministic (`latent_type: mode`); masked physical-space MSE on the
5th free-running step. No input can carry an inlet plane or a noise seed.

One-step predictions from truth frames on test samples 0 and 1 (ny = 48 grid,
shared with 94 training trajectories), fluctuation about the per-cell time mean:

| location | corr(pred', truth') | persistence corr | shuffled control | std ratio pred'/truth' |
|---|---|---|---|---|
| inlet x = -30 | 0.91 / 0.92 | 0.15 / 0.12 | 0.03 / -0.02 | 0.92 / 0.92 |
| x = -22 | 0.93 / 0.93 | 0.22 / 0.18 | 0.03 / -0.03 | 0.94 / 0.94 |
| x = +2 | 0.95 / 0.94 | 0.41 / 0.36 | 0.05 / -0.02 | 0.97 / 0.96 |
| mid-domain | 0.97 / 0.97 | 0.62 / 0.58 | 0.05 / -0.05 | 0.96 / 0.97 |

The inlet fluctuation five seconds ahead is fresh noise that no interior state
can predict, yet the stepper predicts it at r = 0.91 with full amplitude. The
model has memorized the shared sequence: the current inlet column tells it where
in the (single) noise stream it is, and it looks up the continuation. The "learned
inflow turbulence" seen in rollouts is a replay of one realization, and test
RMSE is optimistic in proportion. One-step RMSE is still largest at the inlet
(0.38-0.40 at x = -30 vs 0.13-0.15 mid-domain), consistent with an imperfect
lookup.

## 3. Verdict on the hypothesis

The mechanism is right: a deterministic stepper driven by the interior state
and three scalars cannot know the inlet realization, so pointwise comparison
with a truth trajectory has an irreducible floor set by the inflow noise, and
the MSE-optimal response is to regress toward the conditional mean.

The premise is wrong for the current dataset: truth and surrogate are *not*
driven by different realizations, because every trajectory in train/val/test
replays the same one and the model reproduces it from memory. The mismatch the
hypothesis describes appears the moment the truth comes from any other seed:
an ESMDA member (experiment names "000".."063" give different seeds), a
re-run with a different `experiment_name`, or PALM/uDALES truth runs. There
the surrogate will keep replaying the "999" sequence, so the error will look
like a wrong turbulence realization rather than smoothing.

Two data problems fall out regardless of design: (a) val/test hold out geometry
and parameters but not the noise draw, so they do not measure generalization
over inflow turbulence; (b) a surrogate-driven ESMDA ensemble will carry no
turbulence-realization spread at all (every member replays the same inlet).

## 4. Making the inflow turbulence explicit

The enabling fact is that uDALES' inlet forcing is a pure Python function
`build_driver_planes(seed, params, grid, times)`. The surrogate can therefore be
given the *same* forcing the solver gets, as an input rather than as something to
guess. Options, in order of recommendation.

### 4.1 Deterministic conditioning on the driver planes (primary)

Treat the inlet planes for the interval (t, t + dt] as a boundary forcing input.

Input construction. For frame t, records `r0 + 1 .. r0 + 10` with
`r0 = round((t_phys) / 0.5)` (10 records x 3 components x (ktot, jtot)). Two
representations, to be compared:

- **Raw record stack**: tensor `(B, 3 * 10, ktot, jtot)`; a small 2-D encoder
  maps it to a latent-height plane `(B, Cf, Zl, Yl)`.
- **Frozen-turbulence footprint** (preferred): place record k at
  `x = x_inlet + U_mean(z) * (dt - k * dtdriver)` by Taylor's hypothesis, giving a
  3-D field `(B, 3, nz, ny, nx)` on the state grid that is zero downstream of
  `U * dt` (about 30 m, the 8 upstream padding cells). It is exactly the
  advected inflow the solver will have ingested by t + dt, aligned with the state,
  so the network needs no positional bookkeeping.

Injection point (from the stepper's existing hooks, least invasive first):

1. A second zero-init spatial FiLM on the latent grid, mirroring `geom_film`
   (`tadpole_stepper.py` `ParamConditionedSubnetwork`, `Conv3d(geom_cond_dim, 2*in_dim, 1)`):
   encode the footprint with a light 3-D stem to the latent resolution and pass
   it as a third optional kwarg through `_spatial_recon` and `TadpoleDFT.forward`.
   Identity-at-init is preserved, the frozen AE is untouched.
2. Concatenate the footprint into the skip-mixing adapter input
   (`TadpoleSkipMixing`, levels 4/8) for a high-resolution near-inlet correction.
3. Not recommended: extra folded input channels into the frozen encoder (changes
   its contract, needs AE retraining).

Plumbing: a new per-sample tensor in `TransitionDataset.__getitem__` (planes
generated on the fly from `state.attrs` seed + record offset + `sampled_params`;
cheap, no storage), through `transition_collate`, `BaseTraining._prepare_batch`,
`_model_forward`, `Trainer._final_loss`, `test_neural_surrogate._rollout`, and
`NeuralSurrogateForwardModel._rollout_chunk`. In deployment the surrogate
forward model calls `build_driver_planes` with the member's `experiment_name`,
params and elapsed time, i.e. the identical call `apply_inlet_turbulence` makes
for uDALES. A uDALES truth run and a surrogate rollout then share the forcing
exactly, and pointwise comparison is fair.

Training with K-step pushforward: pass the K plane blocks `(B, K, ...)` like
`params_n (K, P)` and feed block k at step k.

### 4.2 Stochastic stepper (complement, required for PALM / LBM truth)

Where the forcing cannot be exported (PALM's `random-parallel` disturbances,
LBM's Fortran-seeded generator, see §6), the honest model is a conditional
generative step: sample `z_{t+1} ~ p(z_{t+1} | z_t, params, geometry)` in the AE
latent space with flow matching, reusing the plan-07 `LatentFlowMatchingTrainer`
velocity net but conditioned on the previous latent (transition instead of
snapshot). Evaluation switches to distributional metrics (CRPS, spread-skill,
`generator_evaluation.py` profiles/spectra/Reynolds stresses). Per-member seeds
give a natural turbulence spread in ESMDA. Costlier per step (ODE solve) and
harder to keep stable in long rollouts; keep as phase 2.

Hybrid: 4.1 conditioning plus a small stochastic residual for what the planes
do not determine (SGS-scale randomness). Only worth it if 4.1 leaves a
measurable irreducible residual on same-seed twins.

### 4.3 Prerequisite: a dataset with realization diversity

With one shared realization a forcing encoder has nothing to learn from (the
memorization shortcut is cheaper). Before either design:

- Pass a per-sample `inlet_turbulence.seed` (or per-sample `experiment_name`) in
  `fm_overrides` in `generate_random_geometries_training_data.py`, e.g.
  `seed = derive_seed(f"{split}_{sample:04d}")`.
- Stamp `inlet_turbulence_seed`, `inlet_record_offset`, `dtdriver` and the
  profile config into `state.attrs`, and fix (or document) the 205 s label shift
  so the on-the-fly plane generation is exact by construction.
- `extend_training_data.py` can add realization-diverse trajectories to the
  existing corpus rather than regenerating everything, but the val/test splits
  must be regenerated with fresh seeds or they stay contaminated.

### 4.4 Evaluation fixes (independent of the model)

- **Twin-seed floor**: rerun one test geometry with identical params and a
  different seed. The RMSE between twins is the irreducible pointwise error of
  any deterministic surrogate without forcing input, and the number the current
  RMSE curves should be read against. Cheap (one uDALES run), and it makes the
  hypothesis test airtight.
- **Realization-invariant metrics** on `rollout_*/trajectory.pt`:
  `generator_evaluation.py` already provides mean/rms profiles, 1-D spectra,
  Reynolds stresses, W1 histograms; add them to `test_neural_surrogate.py`.
- **Memorization probe** as a regression test: one-step inlet-column
  correlation vs persistence (the table in §2); a healthy model on a
  diverse-seed dataset without forcing input should sit near persistence with
  a std ratio well below 1, and with forcing input near 1 with high r.

## 5. Suggested order

1. Twin-seed uDALES run + realization-invariant metrics (days, no training).
2. Regenerate val/test and extend train with per-sample seeds, stamp attrs.
3. Retrain `dft_s` on the diverse corpus without forcing: establishes the
   conditional-mean baseline and confirms the memorization is gone.
4. Implement 4.1 (footprint + zero-init spatial FiLM); fine-tune from step 3;
   compare pointwise RMSE against the twin floor and against step 3.
5. Wire `build_driver_planes` into `NeuralSurrogateForwardModel` so ESMDA
   members get their own forcing; check ensemble spread vs a uDALES ensemble.
6. Phase 2: stochastic latent transition (4.2) for non-uDALES truth.

## 6. Other backends (for completeness)

- **pypalm**: `inlet_turbulence` maps to PALM's random inflow disturbances
  (not an STG). RNG is `random-parallel` with grid-index seeds and
  `ensemble_member_nr` never set, so every member and re-run gets the same
  realization; nothing is exported and it is not reconstructible in Python.
  Off by default (periodic BC).
- **pylbm**: real synthetic generator in Fortran, seeded from wall clock + rank,
  seed persisted as `seed_<rank>.dat/.orig` (so replayable by re-running the
  Fortran, not in Python). Members cloned from a template with `.orig` share
  the seed; the warm-start seed branch tests the wrong filename. Off by default.

Both are therefore "stochastic in form, degenerate in practice" today and can
only be handled by 4.2-style evaluation, not by 4.1.
